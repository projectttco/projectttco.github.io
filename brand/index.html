System summary

Projecttt should feel warm neutral, strongly hierarchical, native-feeling, restrained in motion, grounded in real evidence, and minimally decorated.

The system deliberately does not require a decorative accent color. Functional color is introduced only when a real information, interaction, state, or accessibility need justifies it.

Source and evidence boundary

This website is a public-safe visual projection, not a second source of truth. Canonical values and rules live in the private Projecttt brand sources and are transformed into this guide.

Missing rules stay missing. Clear-space ratios, minimum logo sizes, and a final downloadable master logo package are currently not yet specified and must not be invented for visual completeness.
